PROJECT GIZMO

How it works?

Gizmo robots are modular and can connect and work together on complex tasks. Here is an example of how such a system could work.

01

Define the task

We start with the goal and working conditions: the location, environment and tasks to be carried out.

02

Choose the modules

The modular design makes it possible to connect robots in a configuration suited to the task — without assuming every setup is the same.

03

Robots work together

Each robot can move independently, respond to changes in its environment and communicate with other devices.

04

Develop the solution

Additional modules can be connected to the system to handle more complex tasks and develop the project in stages.

This is an example of the concept. Configuration details depend on the specific application.
